# Таблица семейных финансов — инструкции для Claude

> Загружается автоматически при работе в этом проекте.

## Что это

Веб-аналог Excel для семейного бюджета: листы-месяцы, произвольные колонки,
формулы, живая синхронизация между устройствами. Пользователей двое.

**Читать в начале работы:**

1. `docs/specs/2026-09-18-design.md` — проектное решение, зачем всё устроено так.
2. `docs/plans/2026-09-18-implementation.md` — план по этапам.
3. `docs/PROGRESS.md` — что уже сделано и на чём остановились. **Обновлять после
   каждого завершённого этапа.**

## Общение

- По-русски, на «Вы».
- Сначала объяснить словами, потом править код.
- Не превышать расход по тарифному лимиту: крупные шаги вместо мелких,
  не перечитывать уже прочитанное, код писать сразу в файлы.

## Правила кода

- `declare(strict_types=1)` везде, PHP 8.4, типы у всех свойств и возвращаемых значений.
- `@throws` там, где исключение уходит наружу; при перебрасывании передавать `previous`.
- Именование: `camelCase` в коде, `kebab-case` в URL, `snake_case` в полях базы.
  Никаких сокращений, имена говорящие.
- Порядок в классе: конструктор, публичные методы, закрытые.
- Комментарии на русском, объясняют суть решения, а не пересказывают код.
- Деньги — только точная десятичная арифметика (`brick/math`), никогда не `float`.
- Слои: контроллер не знает про базу, действие не знает про HTTP, репозиторий
  не содержит бизнес-логики.
- Сообщения интерфейса — на русском.

## Команды

Всё работает через контейнеры, локальные PHP и Node на машине не используются.

```bash
make init      # первичная настройка
make up        # поднять окружение
make test      # все тесты
make shell     # оболочка в контейнере сервиса таблиц
make mongo     # консоль MongoDB
```

## Особенности машины разработчика

- Порт 80 и 8080 заняты Тасти и Drupal, 8081 — WordPress. Этот проект: **8088 и 8448**.
- `docker compose up` на этой машине периодически виснет. Обходной путь:
  `docker compose create` и затем `docker start <контейнер>` по одному.
