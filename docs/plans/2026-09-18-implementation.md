# План реализации

**Спека:** `docs/specs/2026-09-18-design.md`

**Цель:** веб-аналог Excel для семейных финансов с живой синхронизацией между
устройствами, на двух сервисах Laravel 13, MongoDB и RabbitMQ.

**Стек:** PHP 8.4, Laravel 13, MongoDB 8, RabbitMQ 4, Vue 3 + TypeScript + Vite +
Pinia + Tailwind, Laravel Reverb, Pest, PHPStan, Playwright, Docker, GitHub Actions.

## Сквозные требования

Действуют для каждой задачи без повторного упоминания.

- Возвращаемый тип у каждого метода обязателен.
- `@throws` там, где исключение уходит за пределы метода.
- При перебрасывании исключения передаётся `previous`.
- Именование `camelCase` в коде, `kebab-case` в URL, `snake_case` в полях базы.
- Никаких сокращений в именах; имена говорящие.
- Порядок в классе: конструктор, затем публичные методы, затем закрытые.
- Деньги — только точная десятичная арифметика, никаких чисел с плавающей точкой.
- Контроллер не обращается к базе, действие не знает про HTTP, репозиторий не
  содержит бизнес-логики.
- Каждая задача заканчивается зелёными тестами и отдельным коммитом.
- Сообщения интерфейса — на русском.

## Этап 2. Движок формул (от тестов)

**Файлы:** `packages/formula-engine/src/{Lexer,Parser,Ast,Evaluator,Dependencies,
Recalculation,Exceptions,Contracts,Values}`, тесты — `packages/formula-engine/tests`.

Порядок строго от тестов: сначала падающий тест, затем минимальная реализация.

- [ ] `Lexer`: числа, строки, операторы, скобки, точка с запятой, ссылки `B3`,
      `$F$2`, диапазоны `B3:B90`, имена функций.
- [ ] `Parser`: приоритеты `^` > унарный минус > `* /` > `+ -`, скобки,
      вызовы функций. Узлы дерева.
- [ ] `CellReference` и `CellRange` — разбор и печать `A1`, `$F$2`, границы диапазона,
      сдвиг относительной ссылки при копировании.
- [ ] `Evaluator` поверх интерфейса `CellValueResolver`: движок не знает про базу.
- [ ] Точная арифметика через `brick/math`; деление на ноль даёт `#ДЕЛ/0!`.
- [ ] Функция суммы: `СУММ`, `SUM`, любой регистр; аргументы — значения и диапазоны;
      текст внутри диапазона игнорируется.
- [ ] `DependencyExtractor`: из дерева достаются отдельные ссылки и диапазоны.
- [ ] `RecalculationPlanner`: топологическая сортировка затронутых ячеек,
      обнаружение циклов обходом в глубину, цикл даёт `#ЦИКЛ!` во всех ячейках цикла.
- [ ] Ошибки распространяются: ячейка, ссылающаяся на ошибочную, тоже ошибочна.
- [ ] Покрытие движка тестами полное; `phpstan` уровень max проходит.
- [ ] Коммит.

## Этап 3. `sheet-service`: каркас и домен `Auth`

**Файлы:** `services/sheet-service/src/`, домены в `Finance/Domains/`.

- [ ] Установка Laravel 13, пакет `mongodb/laravel-mongodb`, подключение
      `packages/formula-engine` локальным репозиторием Composer.
- [ ] Автозагрузка `Finance\` на каталог `Finance/`; Pest, PHPStan, PHP_CodeSniffer.
- [ ] `Core`: базовый репозиторий над MongoDB, базовое исключение, формат ответа
      об ошибке, идентификаторы.
- [ ] Модель `UserModel`, репозиторий `UserRepository`, уникальный индекс по почте.
- [ ] Действия: `RegisterUserAction`, `LoginAction`, `RefreshTokensAction`,
      `LogoutAction`. Токен доступа подписывается закрытым ключом, токен обновления
      хранится хэшем в коллекции с TTL-индексом.
- [ ] Посредник проверки токена; `GET /api/me`.
- [ ] Команда `finance:create-user` для заведения двух пользователей.
- [ ] Тесты: вход с верным и неверным паролем, обновление пары токенов, повторное
      использование отозванного токена обновления запрещено, истёкший токен доступа
      отвергается, TTL-индекс создан.
- [ ] Коммит.

## Этап 4. `sheet-service`: книги и листы

- [ ] Домен `Workbooks`: модель, репозиторий, действия создания и получения списка,
      проверка доступа участника.
- [ ] Домен `Sheets`: модель, репозиторий, действия создания, переименования,
      удаления, изменения порядка вкладок, изменения ширины колонок.
- [ ] `DuplicateSheetAction` — новый месяц копией: переносятся формулы, оформление
      и ширины, значения не переносятся; относительные ссылки внутри листа остаются
      прежними, ссылки на другой лист не поддерживаются.
- [ ] Версия листа: `IncrementSheetVersionAction`, атомарное `findAndModify`.
- [ ] Маршруты книг и листов, ресурсы ответа.
- [ ] Тесты: чужую книгу не видно, копия месяца содержит формулы и пустые значения,
      удаление листа удаляет его ячейки, порядок вкладок сохраняется.
- [ ] Коммит.

## Этап 5. `sheet-service`: ячейки и пересчёт

- [ ] Домен `Cells`: модель, репозиторий с уникальным и многоключевыми индексами,
      чтение листа целиком одним запросом.
- [ ] Домен `Calculation`: `MongoCellValueResolver` — мост между базой и движком;
      `ApplyCellEditsAction` — сохранить ввод, найти зависимые, пересчитать,
      сохранить, поднять версию, вернуть все изменившиеся ячейки.
- [ ] Поиск зависимых: отдельные ссылки — по многоключевому индексу; диапазоны —
      запросом по вложенным границам.
- [ ] Всё применение пачки — в транзакции MongoDB.
- [ ] `PATCH /api/sheets/{id}/cells` — пакет правок, `PATCH .../cells/format` —
      оформление диапазона, вставка и удаление строк со сдвигом ссылок.
- [ ] Выгрузка листа в CSV.
- [ ] Тесты: сумма пересчитывается при правке слагаемого, цепочка зависимостей в три
      звена, циклическая ссылка не роняет запрос, одновременная правка двух ячеек
      не теряется, вставка строки сдвигает ссылки в формулах.
- [ ] Коммит.

## Этап 7. Публикация в очередь

- [ ] Домен `Messaging`: обменник `finance.events`, ключ маршрутизации
      `sheet.cells.changed`, сообщение с идентификатором для защиты от повторов.
- [ ] Публикация после успешной транзакции, а не внутри неё.
- [ ] Недоставленные сообщения складываются локально и досылаются командой-повторителем,
      чтобы падение RabbitMQ не ломало правку таблицы.
- [ ] Тесты: сообщение публикуется с нужным ключом и телом; при недоступной очереди
      правка всё равно применяется.
- [ ] Коммит.

## Этап 8. `history-service`: журнал

- [ ] Каркас Laravel 13, база `finance_history`, проверка токена открытым ключом.
- [ ] Домен `Messaging`: потребитель очереди как долгоживущая команда, подтверждение
      после записи, повторная обработка отсекается коллекцией с TTL-индексом.
- [ ] Домен `Changelog`: модель, репозиторий, индексы под выборки по листу, по ячейке
      и по времени.
- [ ] `GET /api/sheets/{id}/history`, `GET /api/sheets/{id}/cells/{ref}/history`.
- [ ] Тесты: повторная доставка одного сообщения даёт одну запись, история ячейки
      отдаётся в обратном хронологическом порядке, недоступность базы возвращает
      сообщение в очередь.
- [ ] Коммит.

## Этап 9. `history-service`: снимки, восстановление, сводки

- [ ] Домен `Snapshots`: снимок каждые 100 версий, сборка состояния на произвольную
      версию как снимок плюс проигрывание журнала.
- [ ] `GET /api/sheets/{id}/state?version=` — состояние на момент.
- [ ] Домен `Summaries`: конвейер агрегации по месяцам, кэш результата в коллекции.
- [ ] В `sheet-service` — драйвер обращения к истории и `RestoreSheetStateAction`:
      состояние из истории применяется как обычная пачка правок с новой версией.
- [ ] Тесты: состояние на версию N совпадает с фактическим состоянием на тот момент,
      восстановление порождает новые записи журнала, сводка считает правильно.
- [ ] Коммит.
