# Правила разработки

## Структура

Домены вынесены из каталога приложения Laravel и живут в `Finance/Domains/<Домен>/`
со слоями `Controllers`, `Actions`, `Repositories`, `Contracts`, `Requests`,
`Resources`, `Services`, `Enums`, `Exceptions`, `Providers`.

Разделение слоёв строгое: контроллер не обращается к базе, действие не знает
про HTTP, репозиторий не содержит бизнес-логики.

## Код

- `declare(strict_types=1)` везде, PHP 8.4, типы у всех свойств и возвращаемых значений.
- `@throws` там, где исключение уходит за пределы метода; при перебрасывании
  передавать `previous`.
- Именование: `camelCase` в коде, `kebab-case` в URL, `snake_case` в полях базы.
  Никаких сокращений, имена говорящие.
- Порядок в классе: конструктор, публичные методы, закрытые.
- Комментарии объясняют, почему решение принято именно такое, а не пересказывают код.
- Деньги — только точная десятичная арифметика (`brick/math`), никогда не `float`.
- Сообщения интерфейса — на русском.

## Работа с MongoDB

- Приведение `array` в моделях использовать нельзя: пакет пишет тогда строку JSON
  вместо родного массива, и запросы по элементам перестают работать.
- Имена методов моделей не должны совпадать с именами полей, иначе Eloquent
  принимает поле за связь. То же в классах запросов: `format` занято `Request`.
- Индексы объявляются рядом с репозиторием, который ими пользуется, и создаются
  командой `finance:create-indexes`.
- Всё «прочитать, изменить, записать» заменять операторами обновления (`$inc` и прочие).

Разбор решений по базе — [mongodb.md](mongodb.md).

## Тесты

- Тесты сервисов ходят в настоящую MongoDB, а не в заглушку: проверяется в том числе
  поведение индексов, транзакций и запросов.
- В тестах вещание идёт настоящим драйвером: с пустым драйвером проверка доступа
  к каналу не вызывается вовсе и любой тест на запрет проходит впустую.
- Общие помощники тестов живут в `tests/Pest.php` вместе со своими `use`.
- Каждый этап заканчивается зелёными тестами и отдельным коммитом.

## Окружение

Всё работает в контейнерах, локальные версии PHP и Node не используются.
Проект занимает порты 8088 и 8448.
