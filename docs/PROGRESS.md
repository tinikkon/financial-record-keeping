## Как гонять сквозные тесты

Браузер качается в `e2e/.cache/browsers` и в репозиторий не попадает
(однажды попал и раздул `.git` до 285 мегабайт — см. ниже).

```bash
docker build -t finance-e2e:latest e2e
docker run --rm -v "$PWD/e2e":/e2e -w /e2e --user "$(id -u):$(id -g)" \
  -e HOME=/tmp -e PLAYWRIGHT_BROWSERS_PATH=/e2e/.cache/browsers \
  finance-e2e:latest npx playwright install chromium
make test-e2e
```

Снимок для описания проекта — отдельным прогоном: `СНИМКИ=1 make test-e2e`.

## Найденные ошибки, которые стоили дороже всего

**Поле с приведением типа не обновлялось в базе.** Eloquent отправляет при
обновлении только то, что считает изменившимся, и поле с собственным приведением
(`Decimal128Cast`) в этот список не попадает. Ответ при этом формируется из модели
в памяти и показывает правильное число — поэтому все тесты проходили. Поймали,
только когда тест перечитал лист отдельным запросом. Лечение: `updateOne`
с `upsert` вместо сохранения модели.

**Сырой запрос идёт мимо транзакции.** Следствие предыдущего исправления: сессию
транзакции открывает Laravel, а запрос через коллекцию о ней не знает. Сессия
передаётся явно через `AbstractMongoRepository::sessionOptions()`.

**Ссылка на элемент внутри цикла Vue — массив, а не элемент.** Из-за этого не
ставился фокус в поле ввода ячейки: набиралась только первая цифра. Лечение —
функция вместо строкового `ref`.

**Прерванная команда не записывает файлы, которые в ней были.** Дважды подряд
правка `playwright.config.ts` и перезапись `Dockerfile` оказывались внутри команды,
которую я же и оборвал, — файлы остались прежними, а сборка и прогон честно
работали со старым содержимым. Полчаса ушло на поиск того, чего не было.
Вывод: после записи файла в составной команде проверять, что на диске лежит
ожидаемое, а `pkill -f` по шаблону может совпасть с собственной оболочкой.

**Кэш браузера уехал в репозиторий.** 658 мегабайт в `e2e/.cache` превратили
`.git` в 285 мегабайт, и отправка на GitHub стала отваливаться по таймауту.
Вычищено переписыванием истории, `.gitignore` дописан. Побочный урок: переписывание
истории удаляет такие файлы и с диска — браузер пришлось ставить заново.

**Traefik читает весь сокет Docker** и подхватывает контейнеры соседних проектов.
Нужен `providers.docker.constraints` по метке проекта.

**Проверка здоровья из образа FrankenPHP** опрашивает административный интерфейс
Caddy, который выключен намеренно. Контейнер числился нездоровым, и traefik его
не маршрутизировал. Задана своя проверка.

## Принятые решения, о которых легко забыть

- Разделитель аргументов в формулах — и `;`, и `,`; дробная часть — всегда через точку.
- Порядок унарного минуса и степени взят из Excel: `-2^2` равно четырём.
- Имена функций работают по-русски и по-английски, регистр не важен.
- Ячейки — отдельная коллекция, а не массив внутри листа. Причины в спеке.
- Диапазоны в зависимостях хранятся границами, а не списком ячеек.
- Порты окружения: 8088 и 8448.
- Приведение `array` в моделях использовать нельзя: пакет MongoDB пишет тогда
  строку JSON вместо родного массива, и запросы по элементам перестают работать.
- Имена методов моделей не должны совпадать с именами полей (`kind` → `cellKind`),
  иначе Eloquent принимает поле за связь. То же в запросах: `format` занято
  классом `Request`.
- Статический анализ сервисов ещё не настроен — сделать в этапе с оформлением сборки.
- В тестах вещание должно идти настоящим драйвером (`BROADCAST_CONNECTION=reverb`):
  с пустым драйвером проверка доступа к каналу не вызывается вовсе и любой тест
  на запрет проходит впустую.
- Общие помощники тестов живут в `tests/Pest.php` вместе со своими `use`.

## Как продолжить работу

1. Поднять окружение: `docker compose up -d mongo mongo-replica-set-init rabbitmq`
   (если `compose` виснет — стартовать контейнеры по одному через `docker start`).
2. Тесты сервиса таблиц:
   `docker run --rm --network finance_finance -v "$PWD":/app -w /app/services/sheet-service/src --user "$(id -u):$(id -g)" -v "$PWD/docker/secrets":/run/secrets:ro finance-sheet-app:latest vendor/bin/pest`
3. Тесты движка формул — то же, но `-w /app/packages/formula-engine`.
4. Индексы после правки репозиториев: `php artisan finance:create-indexes`.
- Тесты сервисов ходят в настоящую MongoDB, база `finance_sheets_test`.
- Ключи подписи токенов лежат в `docker/secrets/`, в репозиторий не попадают,
  создаются командой `make keys`.
